# UZStar 2.2 — ishga tushish va asosiy amallar

- Kirish oynasi, yuklash oynasi va profil tahrirlash holatlari mustahkamlandi.
- Videoni yuklash jarayoniga progress indikator qo‘shildi.
- Backend profil ismini yangilash uchun `PATCH /api/me` endpointini qo‘llaydi.
- Yuklagan videoning egasi UI’da to‘g‘ri aniqlanadi.
- Server holati menyuda ko‘rsatiladi.
- Mahalliy namuna video qo‘shildi, tashqi demo URL’ga qaramlik kamaytirildi.
- Mobil menyu, sahifa hash navigatsiyasi va reduced-motion qo‘llovi saqlab qolindi.

## Sinovlar
Python/JavaScript sintaksisi, HTTP API, ro‘yxatdan o‘tish, sessiya, video yuklash, izoh, layk, obuna, video Range so‘rovi va profil yangilash sinovdan o‘tkaziladi.
