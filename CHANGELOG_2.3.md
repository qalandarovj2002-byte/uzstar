# UZStar 2.3 — navigatsiya va ishonchlilik

- Menyu va sahifa tugmalari endi IndexedDB, lokal video tiklash yoki server javobini kutmasdan darhol ulanadi.
- Dastlabki sahifa birinchi ekranda sinxron ochiladi; keyingi server ma’lumotlari yuklanganda kontent yangilanadi.
- Mahalliy ma’lumotlar yoki server yuklanishidagi xatolar navigatsiyani to‘xtatmaydi.
- Service Worker kesh versiyasi yangilandi, eski JavaScript/CSS keshida qolib ketish ehtimoli kamaytirildi.
- Navigatsiya, video kartalari, qidiruv, profil, Shorts va sozlamalar bo‘yicha takroriy brauzer sinovlari qo‘shildi.
- `run_uzstar.bat` endi 8000-port band bo‘lsa, keyingi bo‘sh portni tanlaydi. Bu eski server ochiq qolganida brauzerning tasodifan eski UZStar nusxasini ko‘rsatishining oldini oladi.
